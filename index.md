# YouTube Yukleyici

YouTube Yukleyici is a personal desktop tool for macOS. It uploads the owner's own videos, thumbnails and captions to the owner's own YouTube channels and schedules their publication, using the YouTube Data API.

It is not a public service and is used only by its owner.
